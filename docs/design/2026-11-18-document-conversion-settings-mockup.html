What lmgw can turn into text for a model on this computer, and what one install would add. Checked 2 minutes ago.

What you can convert

Text, Markdown, CSV, web pagesalways handler text.native · html.native
Word, PowerPoint, Excel, OpenDocumentalways, with headings and tables handler office.native · budget MAX_UNCOMPRESSED_BYTES 1 GiB
PDFtext, headings and tables handler pdf.poppler · pdftotext, pdftohtml, pdftoppm
Scanned PDF pages and photosnot read yet: install text recognition or choose a model below handler none · needs tesseract or a vision model
Old Word and PowerPoint files (.doc, .ppt)through LibreOffice handler legacy.libreoffice · private profile per run, macros off
E-books (EPUB) and e-mails (.eml)always handler epub.native · mail.native
RTF, LaTeX, Org and similarinstall Pandoc handler none · needs pandoc
Pictures in documentskept in place, not described yet: choose a model below pictures.export · PDF via poppler image positions · vector drawings need the layout model
Audiothrough example-asr alias example-asr · CPU row, keeps working under the hold
Videoinstall ffmpeg handler none · needs ffmpeg + a speech model
